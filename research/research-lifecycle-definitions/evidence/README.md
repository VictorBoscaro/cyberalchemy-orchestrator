# Research Lifecycle Definitions — Evidence Workspace

This directory holds bounded, attributable evidence collected for
`research/research-lifecycle-definitions/`.

Evidence stored here is temporary research material:

- it is not a canonical ontology;
- it does not establish valid node kinds or edge kinds;
- it does not become runtime authority by being recorded;
- it may be quoted or promoted into `research.md` and `findings.md` only after source and claim
  verification;
- every evidence document must name its source paths and distinguish direct observations from
  interpretation.

The first proposed evidence records are:

- `canonical-kinds-normative-scout.md` — schema, kind, edge, and validation contracts;
- `canonical-kinds-usage-scout.md` — instance, lifecycle, authority, and drift evidence.

No scout evidence has been accepted yet.
