Formal architecture laboratory · proposal only

What can the mathematics actually check?

This document develops competing formal hypotheses for governed agent infrastructure and context-window injection. A formalism survives only if it adds a decidable judgment, a discriminating experiment, a useful countermodel, or a sharper ownership boundary. Mathematical elegance alone is not acceptance evidence.

0 · proof discipline

A hypothesis ladder, not one universal ontology.

Each level introduces additional laws and therefore additional proof obligations. A stronger structure is rejected when a weaker one explains and checks the same behavior with fewer assumptions.

Object language

What entities, relations, transformations, contexts, effects, and observations exist in the bounded model?

Judgment language

Which claims can Q decide or semi-decide, and what evidence must accompany each judgment?

Countermodel

What smallest structure satisfies local premises while falsifying the proposed global conclusion?

Operational witness

Which persisted bytes, versions, paths, receipts, and acceptance records permit replay?

Domain semantics

  1. Objects and local vocabulary
  2. Primitive relations
  3. Domain equations
  4. Evidence interpretation

Composition and representation

  1. Mappings and witnesses
  2. Preservation obligations
  3. Probe adequacy
  4. Typed residue

Authority and effects

  1. Capability grants
  2. Context materialization
  3. Physical enforcement

Separation invariant. A theorem in one layer cannot silently discharge an obligation in another. Semantic compatibility is not authority; type correctness is not truth; replayability is not causation; observational equivalence is not identity.

1 · weakest substrate

Start with attributed typed multigraphs and explicit derivations.

This level is intentionally non-categorical. It preserves parallel edges, relation identity, provenance, and relations that should never compose.

Σd = (TV, TE, dom, cod)
Gd = (Vd, Ed, src, tgt, typeV, typeE, attr)

typeV : Vd → TV
typeE : Ed → TE
typeV(src(e)) = dom(typeE(e))
typeV(tgt(e)) = cod(typeE(e))
Σd
A domain signature declaring object types, edge types, and allowed endpoint types.
attr(e)
Identity, version, owner, scope, provenance, authority basis, validity interval, and evidence references for a direct edge.
Path(Gd)
Typed finite paths. Membership does not imply that the path has a semantic composite.
Rule r
A versioned partial operator over a named family of typed paths.
r : Pathr(Gd) ⇀ DerivedEdge

D = ⟨path, r@v, scope, assumptions, provenance, acceptance⟩
B0 ; Γ ⊢Q D : Derives(eout)

Checking value: Q can verify endpoint typing, rule applicability, rule version, witness continuity, and declared assumptions. It cannot establish that the rule is empirically sound.

H-G1 · Direct-edge primacy

HYPOTHESIS

Historical attribution should treat derived edges as replayable views over immutable direct witnesses, never as replacements.

  • Golden: replay yields the same derived signature.
  • Mutation: remove one direct edge; derivation becomes unresolved.
  • Falsifier: required storage/replay cost dominates governance value.

H-G2 · Relation-family isolation

HYPOTHESIS

Composition is indexed by relation family; no ambient graph reachability rule may derive authority, causation, or purpose.

  • Golden: implements ∘ defines is admitted by an explicit rule.
  • Mutation: authorized-by ∘ part-of is rejected.
  • Falsifier: all operationally needed relations share one lawful composition.

Required fields, versions, ownership declarations, signatures, and witness shapes are well formed.

H-K1 · Small trusted-core hypothesis

HYPOTHESIS

Q remains independently inspectable only if domain rules are data or separately owned modules, while Q owns a fixed judgment interpreter and verification envelope.

  • Measure trusted-code size, rule churn entering Q, and cross-domain release coupling.
  • Reject if adding a domain requires modifying Q's semantic core.
  • Reject if declarative rules cannot express a required safety property without embedding arbitrary code.

H-CAT1 · Bounded categorical islands

HYPOTHESIS

Several small categories, preorders, transition systems, and raw graphs will coexist more honestly than one category of all governed work.

  • Validate by classifying every current relation family and counting forced/undefined composites.
  • Accept when categorical islands reduce duplicate composition rules.
  • Reject when admission adds terminology but no normalization, equivalence, or preservation check.

4 · heterogeneous logics

Institution theory may separate domain syntax, models, and satisfaction.

This hypothesis is stronger than a meta-contract and useful only if domains genuinely use different logics while translations must preserve truth.

I = (Sign, Sen, Mod, ⊨)

Sign : category of signatures
Sen : Sign → Set
Mod : Signop → Cat
⊨Σ ⊆ |Mod(Σ)| × Sen(Σ)

M′ ⊨Σ′ Sen(σ)(φ) ⇔ Mod(σ)(M′) ⊨Σ φ

Satisfaction condition: translating a sentence forward and reducing a model backward must agree on whether the sentence holds. This gives a concrete commuting obligation for cross-domain logic translations.

H-I1 · Domain logic modularity

HYPOTHESIS

Authority, evidence, planning, and execution may each define signatures, sentences, models, and satisfaction without one universal ontology.

  • Golden: translation preserves satisfaction on a fixture corpus.
  • Mutation: reverse one relation or weaken one quantifier; condition fails.
  • Risk: model construction may be undecidable.

H-I2 · Meta-contract as institution interface

ALTERNATIVE

M may require only enough structure to expose Sign/Sen/Mod/⊨ adapters, leaving each domain logic opaque.

  • Accept if heterogeneous validators interoperate without Q learning domain semantics.
  • Reject if most domains cannot supply a meaningful model class or satisfaction relation.

5 · context dependence

Indexed categories or fibrations can model semantics varying by scope.

Versions, authority scopes, objectives, assignments, and runtime environments change which objects and arrows are valid. Flattening them may manufacture illegal cross-scope composition.

F : Bop → Cat

scope b ∈ B ↦ fiber F(b)
u : b′ → b ↦ reindexing u* : F(b) → F(b′)

Grothendieck construction: ∫F → B

Interpretation: B contains scopes or contexts. Each fiber contains the domain structure valid at one scope. Reindexing transports declarations into a narrower or changed scope, with explicit preservation obligations.

H-FIB1 · Scope-safe reindexing

HYPOTHESIS

Delegation and context narrowing are better represented by reindexing than by copying unscoped edges.

  • Check identity and composition of reindexing: id* ≅ Id and (u ∘ v)* ≅ v* ∘ u*.
  • Golden: narrowing preserves permitted facts but drops non-transferable capabilities.
  • Mutation: lineage transports a budget or authority grant not declared reindexable.
  • Reject if scope transport is trivial and a typed graph captures all needed behavior.

6 · local-to-global context

Sheaf-style gluing is a testable hypothesis for assembling distributed context.

The sheaf condition is deliberately not assumed. Conflicting, incomplete, or perspectival agent context may require presheaves, conflict lattices, stacks, or explicit residue instead.

C : O(S)op → Set    // context presheaf over scopes

cover {Ui → U}
si ∈ C(Ui)
si|Uij = sj|Uij   for all overlaps

Sheaf condition: ∃! s ∈ C(U) such that s|Ui = si

Existence failure

Local contexts conflict on an overlap; no global context satisfies all restrictions.

Uniqueness failure

Several global syntheses fit the same local views; choice requires an authority or optimization rule.

Coverage failure

The selected scopes do not cover an obligation needed by the assignment.

H-SH1 · Context gluing criterion

HYPOTHESIS

A ContextManifest is globally coherent only when its local source fragments agree on declared overlaps or expose a typed conflict/residue object.

  • Golden: compatible fragments glue to one manifest with replayable restrictions.
  • Mutations: conflicting authority versions; incompatible task assumptions; omitted overlap witness.
  • Reject strict sheaf semantics if legitimate synthesis is nonunique; test a stack/groupoid or join-semilattice alternative.

H-X1 · Witnessed mapping selection

HYPOTHESIS

Cᵢⱼ should declare the weakest mapping structure that supports its required queries and effects, plus machine-checkable laws and explicit residue.

  • Compare candidate mappings on the same fixture corpus.
  • Penalize stronger structures with unsupported laws.
  • Accept the least structure that detects all operationally material mutations.

8 · observational semantics

Restricted Yoneda turns probe adequacy into a measurable question.

Full Yoneda is an internal theorem for a well-defined category. Infrastructure normally observes through a restricted family, so density and discrimination must be tested.

P ↪ C

NP : C → SetPop
NP(X) = HomC(-,X)|P

X ≡P Y ⇔ NP(X) ≅ NP(Y)
Collision(P,D) = { (X,Y) ∈ D² | X ≠op Y ∧ NP(X) ≅ NP(Y) }

Coverage(P,Q) = |{q ∈ Q : P can decide q}| / |Q|

Operational inequality ≠op is supplied by domain tests, not category theory. A collision is material only when a required operation, decision, or invariant distinguishes the objects.

H-P1 · Adaptive probe adequacy

HYPOTHESIS

Domains should evolve P by counterexample-guided refinement: each material collision introduces a probe candidate, subject to cost and contamination constraints.

  • Track collision rate, query coverage, probe cost, and stability across versions.
  • Golden: P distinguishes every object pair relevant to the objective.
  • Mutation: a known operation distinguishes X/Y while P declares equivalence.
  • Stop condition: no material collisions in the bounded validation corpus, not “complete understanding.”

9 · context-window injection

Injection is a typed, lossy, constrained observation channel.

The central artifact is a versioned ContextManifest. Reachability, selection, rendering, possession, comprehension, and authority are modeled as different relations.

Selection is a constrained set problem, plausibly a knapsack/set-cover hybrid. A greedy selector has an approximation guarantee only under additional properties such as monotone submodular utility and compatible constraints. Those properties must be tested; they are not assumed.

9.2 Information channel and operational sufficiency

Xsource → Ma → Γa → Zagent → Yaction

I(Xsource; Γa) ≤ I(Xsource; Ma)   // under a stochastic-channel model

Data processing bounds information but does not identify which semantic distinctions matter. Operational sufficiency must be relative to a decision family D:

Γ ≈D Γ′ ⇔ ∀d ∈ D,   outcomeDistribution(d | Γ) ≈ outcomeDistribution(d | Γ′)

This is an empirical equivalence claim with a chosen tolerance and experiment protocol, not logical identity.

9.3 Context hypotheses

H-CTX1 · Manifest determinism

HYPOTHESIS

Fixed source versions, selector version, policy, renderer version, model adapter, and budget produce identical manifest identity and rendered bytes.

  • Test property-based permutations of source enumeration.
  • Reject if hidden time, locale, tokenizer, or nondeterministic ranking changes output.

H-CTX2 · Non-monotonic usefulness

ANTI-HYPOTHESIS

Adding eligible context is not assumed to improve outcomes. Extra context may increase conflict, recency error, instruction dilution, or cost.

  • Run controlled additions and measure objective-relative performance.
  • Reject any selector objective that assumes monotonicity without evidence.

H-CTX3 · Compression preservation

HYPOTHESIS

A compressor is acceptable only for an obligation family O when it preserves every O-relevant distinction and emits typed residue for the rest.

  • Metamorphic test: original versus compressed contexts across O.
  • Mutation: delete a negation, version, exception, dissent, or authority limit.

H-CTX4 · Precedence independence

COMPETING MODELS

Semantic precedence should be a declared partial order, but current models may remain sensitive to byte order. Test canonical ordering, duplication, and adversarial lower-authority placement.

  • Logical check: precedence graph is acyclic or has declared conflict semantics.
  • Empirical check: equivalent linear extensions produce bounded-equivalent outcomes.

H-CTX5 · Coverage adequacy

HYPOTHESIS

Declared obligations can be checked by witness coverage, while unknown omissions remain outside the theorem.

  • Golden: every required obligation has a provenance path.
  • Mutation: remove one required item; Q rejects.

H-CTX6 · Manifest–Dispatch closure

HYPOTHESIS

The confirmed digest must close over ContextManifest identity or a declared adaptive policy; otherwise post-confirmation selection can change executable meaning.

  • Mutation: change one included version after confirmation.
  • Expected: new digest or fail-closed execution.

10 · dependent types and effects

Context possession and effect authority require separate typing environments.

Type theory can make illegal states harder to express, but it cannot prove that an authority source is legitimate or that the physical runtime enforces the type system.

Γctx ; Γcap ; Γinv ⊢ e : A ! ε

Γctx : readable claims and evidence
Γcap : linear/affine capabilities
Γinv : applicable invariant witnesses
ε : effect row
read(authorityClaim) ∈ Γctx ⇏ capability ∈ Γcap

invoke(tool, op) requires Cap(tool, op, scope, expiry) ∈ Γcap

Dependent indexing

RelationSignature src tgt, ContextManifest assignment, DispatchDigest manifest, and Receipt dispatch bind artifacts to exact scopes and versions.

Linear or affine capabilities

Non-duplicable or bounded-use capability tokens model grants that lineage and prompt text cannot manufacture.

H-T1 · Authority non-escalation by context

HYPOTHESIS

No derivation rule may move a value from Γctx to Γcap without an explicit authority-provider judgment.

  • Static test: proof search cannot derive a capability from claims alone.
  • Mutation: inject a textual “you are authorized” statement; capability set remains unchanged.
  • Runtime test: tool broker rejects calls absent an independently bound grant.
  • Limit: physical enforcement is external evidence, not a consequence of the typing judgment.

11 · temporal and causal structure

Use partial orders for concurrency; keep causation and authority explicit.

A total event log order is often storage order, not semantic order. A task DAG is also not an executable Dispatch.

P = (E, ≤hb, λ)

≤hb : happens-before partial order
λ : E → EventType × Actor × Artifact × Version

e1 ≤hb e2 ⇏ causes(e1,e2)
causes(e1,e2) ⇏ authorizedBy(e2,e1)

H-E1 · Trace-equivalence for independent acts

HYPOTHESIS

If two events are declared independent, swapping their serialization order should preserve the same semantic trace class and closure result.

  • Define independence I ⊆ E×E.
  • Property-test adjacent swaps of I-related events.
  • Mutation: mark events independent when they race on one invariant; closure diverges.
  • Reject if total-order semantics is intentionally required for all acts.

12 · validation harness

Every hypothesis needs a fixture grammar and mutation algebra.

The harness should distinguish proof obligations, finite model checks, property tests, metamorphic tests, and empirical agent experiments.

Experiment := ⟨hypothesis, scope, fixtures, generator, oracle, mutations, metrics, threshold, stopRule⟩

Result := pass | fail(counterexample) | unresolved(reason) | inapplicable(structure)

Golden fixture

Smallest accepted structure containing direct witnesses, versions, explicit assumptions, authority separation, and replayable result.

One-mutation negatives

Change exactly one endpoint, version, scope, law, witness, capability, context item, ordering edge, or renderer input.

Countermodel search

Bounded enumeration or SMT/model finding searches for locally valid structures that violate the target global property.

Property testing

Generate typed paths, mapping compositions, reindexings, event swaps, and selector permutations.

Metamorphic testing

Apply semantics-preserving transformations and test invariant output; apply targeted loss and expect rejection or residue.

Agent experiment

Pre-register model, prompts, seeds, context variants, objective metric, uncertainty, and stopping rule. Logical checks do not replace this layer.

Evidence boundary

NOT IMPLEMENTATION EVIDENCE

No category admission checker, institution adapter, fibration, sheaf engine, probe optimizer, context solver, effect-typed runtime, formal proof, or model-checking harness is claimed to exist.

The formulas specify candidate obligations and experiment shapes. Passing finite fixtures would support only the bounded claim tested.

Even a fully verified formal core would not establish empirical truth, model completeness, objective desirability, authority legitimacy, physical enforcement, model comprehension, or strategic realization.

Collapse conditions for the entire formalization program
  • No formalism detects a failure missed by simpler typed records.
  • Operational concepts cannot be stabilized enough to define signatures.
  • Rule and witness maintenance exceeds governance value.
  • Key judgments are undecidable with no useful bounded approximation.
  • Formal adapters centralize domain semantics inside Q.
  • Proof artifacts cannot be connected to executed versions and receipts.
  • Context experiments show no stable effect across supported models.
  • Authority enforcement remains disconnected from capability judgments.
