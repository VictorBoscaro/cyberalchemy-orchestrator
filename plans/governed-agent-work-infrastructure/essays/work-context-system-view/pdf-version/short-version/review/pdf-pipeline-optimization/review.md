**Zero-findings check.** No attacker returned zero findings overall — 3/14/14/15 across the four lenses — so the "all four return zero" failure mode did not occur. Rissanen is the only attacker who filed explicit survived-attack (zero-finding) items, and all four carry a stated, measured defence: corner-gradient patterns (8 shared Pattern objects, 517 B), font-subset overlap (no shared base-font+weight pair), dead CSS (a direct occurrence count — this defence did not hold), and SVG-to-vector (rejected on pixel-identity grounds, a procedural inadmissibility, not a "no problem" claim). **Collapse note (P14).** No premature convergence. Verified against the positions file: every attacker moved on evidence and every attacker refused at least one concession. Round 2 also produced three *new* findings (Nyquist F14, Pohl #13/#14) — a collapsing group does not add findings.
