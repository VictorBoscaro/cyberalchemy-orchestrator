# Vault Essays

This directory contains canonical essays whose arguments concern the organization and evaluation
of knowledge itself. An essay presents a committed, revisable argument; its presence here does not
turn a draft proposal into governing law.

## Contents

- [Evaluating Text as Composition](evaluating-text-as-composition.md) proposes a practical model
  for evaluating how a text's parts, sequence, claims, and presentation work together to produce an
  intended effect on a reader.
