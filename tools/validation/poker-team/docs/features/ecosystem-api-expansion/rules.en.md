## Rollout Rules

- Phase 1 must deliver finance automation first (make-up, settlement, payout traceability).
- Phase 2 depends on stable event ingestion from phase 1 to enable workflow modules.
- Phase 3 is allowed only after pilot KPIs are met and webhook reliability is accepted.

## Product Rules

- Every API capability must map to a measurable manager-facing outcome.
- No feature enters roadmap without a direct monetization path (SaaS tier or API usage).
- A single player profile must unify financial and study telemetry views.

## Partnership Rules

- Data freshness and delivery SLAs are mandatory before commercial launch.
- Historical backfill access is required for progression and risk analytics accuracy.
- Scope boundaries by game type and stake level must be explicit before pilot start.

## Governance Rules

- Access must be role-aware (owner, manager, coach, player).
- Sensitive financial operations must be auditable end-to-end.
- Event idempotency is required for payout and settlement automation.
