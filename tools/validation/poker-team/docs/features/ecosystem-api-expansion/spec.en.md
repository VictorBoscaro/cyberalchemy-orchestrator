## Goal

Define an API-first partnership slice that converts internal stable operations into a scalable B2B SaaS and API product line.

## Scope

- API capability map required for operational finance and player management
- Phase-based rollout from operational integration to partner platform scale
- Commercial alignment for hybrid monetization (SaaS base plus API usage)

## Out of Scope

- Low-level protocol implementation details (OAuth internals, infra topology)
- Full public API marketplace launch in phase 1

## Acceptance Summary

- Clear API domain priorities with business outcomes
- Dependency-ordered delivery plan across docs, backend, and web
- Explicit partner ask and pilot criteria for executive negotiation
