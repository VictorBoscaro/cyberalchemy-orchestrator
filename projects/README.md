# Projects

This directory collects repository-owned projects with an autonomous identity and a boundary that
may later be extracted into another repository.

The collection contract is provisional. The bootstrap projects below will provide evidence for
governing this directory and its children.

## Projects

- [`schema-service/`](schema-service/) — shared schema identity, resolution, definition, and
  validation infrastructure.
- [`folder-schema-service/`](folder-schema-service/) — folder-specific schemas, composition rules,
  and conformance cases.
- [`cyberalchemy-mvp-proposal/`](cyberalchemy-mvp-proposal/) — initial product proposal for a
  chat Orchestrator, governed Dispatch runtime, Scouts, skills, and Craft-backed project state.
