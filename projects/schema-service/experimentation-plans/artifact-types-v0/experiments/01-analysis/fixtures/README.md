# Fixtures

No concrete fixture is admitted yet. Fixtures are frozen inputs to the later run and must be selected
under the pre-registered `criterion.md`, not used to tune the criterion after seeing outcomes.

The future criterion must account for at least:

- one ordinary example of each active subtype;
- one ambiguous observed-phenomenon versus observational-study case;
- one change of representation that preserves artifact identity;
- one reclassification that creates a new manifest revision;
- one new candidate schema revision that leaves prior runs reproducible;
- one normative-only consumer that must reject an experimental reference.

This list declares pressure cases, not samples, thresholds or expected verdicts.
