# Runs

No experiment run exists. A later run must preserve, for every fixture:

- frozen criterion reference and digest;
- experiment manifest digest;
- candidate revision ID and definition digest;
- artifact identity and manifest revision;
- representation identity and snapshot digest;
- validator identity and mode `experimental`;
- validation report;
- any subsequent change or reclassification as a new observation or revision.

Promotion or later schema publication must never modify these records.
