# Distill validation
Budget assumption: standard, because the target crosses authority, durable state, lifecycle, and compatibility boundaries.

Smallest coherent unit: **host-committed terminal response receipt materialized into a verified downstream input binding**.

- Removing host-owned capture makes attribution forgeable.
- Removing durable artifact commit makes replay unverifiable.
- Removing the pre-confirmed slot mapping conflates topology with data dependency.
- Removing launch verification recreates the original `slots: []` failure.
- Expanding into general connection semantics or provider-complete evidence exceeds the accepted decision.

Recomposition: this unit fits beneath ACI's publish/materialize/start lifecycle and above the current Python + SQLite host workflow bridge without claiming to complete the broader workflow graph.
