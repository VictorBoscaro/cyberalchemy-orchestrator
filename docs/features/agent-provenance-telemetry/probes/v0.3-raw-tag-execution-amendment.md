# v0.3 raw-tag probe execution amendment

## Purpose

The original P001–P007 protocols are immutable historical preregistrations. They assumed a seed tag
registry that discovery v0.3 deliberately removed. No probe has run. This amendment specifies the
raw-string execution before results exist; it does not edit the older files or rescue an unfavorable
result after observation.

## Common treatment

- Agent payload is the exact array accepted by `deposit_topic_tags(tags: string[])`.
- Preserve raw UTF-8 strings and order.
- The comparison key performs Unicode normalization, lowercase and surrounding-space removal only.
- Do not stem, translate, split, merge or map synonyms.
- No seat sees peer emissions from the same round before depositing its own.
- Record model, persona/profile, prompt version, fixture and activation for stratification.
- Report exact strings that also appeared in the prompt separately from strings not suggested there.

The primary operational prompt uses examples because they improve instruction clarity. To estimate
prompt-induced agreement, run every one of the 12 fixtures once in each of three conditions, using
fresh informationally isolated seats with the same composition stratum:

1. the operational prompt with its normal examples;
2. the same prompt with examples removed; and
3. the same prompt with domain-appropriate examples rotated so no example label is shared with
   condition 1.

This produces 36 fixture-condition bundles. Counterbalance condition order across fixtures with a
preregistered Latin-square assignment, and never reuse a seat's memory across conditions. The prompt
condition is fixed before emission and included in every result. Agreement pooled across conditions
is descriptive only; paired within-fixture differences estimate priming, and the no-example condition
is the conservative estimate of spontaneous lexical overlap.

## Probe translations

### P001 — agreement

Use exact mechanically normalized strings wherever the original protocol says resolved tag ID.
Report Jaccard overlap, pairwise F1 and shared-string counts both including and excluding labels shown
in that seat's prompt. Do not interpret low lexical agreement as absence of conceptual agreement.

### P002 — drift

The historical P002 treatment and decision gate are `inapplicable` to v0.3 because they require an
initial and a close emission while v0.3 fixes one close emission per activation. P002 is not executed
as a cadence-selection experiment in the first deployment, and its resolved-ID thresholds are not
reinterpreted after results.

Longitudinal additions, removals and retention between adjacent close emissions of the same logical
seat and dispatch may be reported descriptively when natural resumptions exist. The unit is one
ordered adjacent-activation pair; all eligible pairs are included; no minimum count or inferential
claim is made. Registry churn, remapping, `initial → close` duplicate rate and the historical cadence
gates are all `inapplicable`. A future controlled cadence experiment requires a new preregistration.

### P003 — vocabulary observation

P003 no longer tests seed-registry coverage. For each chronological observation window report:

- distinct normalized strings and singleton proportion;
- new-string rate relative to all earlier windows;
- frequency and seat/fixture distribution of repeated strings;
- edit-distance or embedding clusters only as exploratory, non-authoritative analyses; and
- examples where blind reviewers believe different strings express the same topic.

This probe can recommend research into equivalence management. It cannot accept a mapping or block
raw capture.

### P004 — capture cost and noise

Keep the original latency/token/noise outcomes. Add tool-boundary rejection rate and retry count.
Prompt examples are treated as suggested labels, not independent discoveries.

### P005 and P006 — source capture and lineage

Unchanged except that manifests reference raw topic-observation IDs and contain no resolution or
registry references.

### P007 — lens

Inherit the historical unit (12 fixtures, at least three isolated seats per fixture), evaluator design,
gold-label procedure, metrics, structural gates and decision thresholds, with these explicit
substitutions:

- `B0` is the canonical `seat × normalized-string` incidence matrix with counts and emission refs;
- `B1` is per-seat lists plus one support-count-sorted global string list with the same evidence;
- `L1` is the same evidence organized as thresholded shared strings and per-seat perspectives;
- the canonical round-trip relation is
  `seat × activation × normalized-string × count × emission_ref`;
- resolved IDs, registry version, resolution manifests, residue and temporal drift are `inapplicable`;
- residue precision/recall and residue-set Jaccard are therefore not computed; and
- every remaining historical metric and numeric threshold is inherited unchanged.

No condition may introduce a string absent from its supporting emissions. `B0`, `B1` and `L1` receive
byte-identical raw observation manifests. A comparison is invalid if any condition has different
strings, counts, seats, activations or emission references.

## External broad/granular rubric

Broad/granular is an evaluation label, never part of the captured payload.

- `broad`: a field or context that could reasonably contain several distinct problems in the fixture;
- `granular`: a concrete concept, method, mechanism or named problem materially used in the fixture;
- `unclear`: neither label can be assigned from the fixture and activation summary without guessing.

Two annotators, blind to seat identity and prompt condition, independently label a fixed random sample
of tag occurrences. Report raw agreement and Cohen's kappa. Adjudication may create an analysis label
but never changes the stored string. Report the coarse/granular mixture only when kappa is at least
0.60; otherwise report that the rubric was not reliable enough for that sample.

## Interpretation boundary

The observations can establish lexical reuse, divergence, prompt sensitivity, cost and provenance.
They cannot by themselves establish semantic equivalence, consensus, taxonomy quality or a need for
a canonical registry.
