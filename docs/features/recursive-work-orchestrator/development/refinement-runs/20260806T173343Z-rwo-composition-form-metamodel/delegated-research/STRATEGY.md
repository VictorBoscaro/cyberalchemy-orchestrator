# Governed research strategy — RWO composition-form metamodel

Status: confirmed material strategy; registration and execution pending validation.

## Trigger and scope

The target is a new candidate that must reconcile three independent lenses without collapsing source context or letting parent synthesis hide disagreement. The agents are advisory except for the evidence-closed writer, who may write only `findings.md`.

## Lanes

| Group | Agents | Purpose |
| --- | --- | --- |
| explorers | Eilenberg; Hewitt; Riehl | form/compiler semantics; condition/owner adversary; ontology/validation architecture |
| synthesizer | Mac Lane | exact candidate package and evidence matrix |
| reviewers | Tetlock; Capucci; Meadows | precedent, non-vacuity, definitional soundness |
| writer | Shannon | evidence-closed `findings.md` only |
| auditor | Brandenburg | findings-only approval or one bounded revision |

Flow: `explorers -> synthesizer <-> reviewers -> evidence closure -> writer <-> auditor -> parent`.

Evidence contract: `exact-binding`. Inventory is discovery-only. Direct current source selectors and finite witnesses are mandatory. No implementation or ontology mutation is permitted.
