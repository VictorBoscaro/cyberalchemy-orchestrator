## Problem definition

RWO names seven composition forms and says they compile to explicit event-triggered graphs, but it does not yet own an exact common definition/instance model, closed operand roles, form-specific schemas, condition-family/evaluator boundaries, deterministic compilation receipt, or complete ontology and validation contract.

The problem is therefore:

> Define the smallest common form model that supports deterministic compilation and queryable validation while preventing structural orchestration from becoming a universal domain, recovery, reasoning, admission, authority, or effect-policy engine.

## Falsifiable hypothesis

`CompositionFormMetaModel@candidate-1` is sufficient if and only if:

1. one common immutable envelope carries only identity, kind, version, boundary, closed payload, and provenance;
2. every form payload has closed operand roles, cardinalities, admissible conditions, policies, limits, and failure rules;
3. only event selection, structural readiness, exact route matching, and bound availability are evaluated by RWO;
4. all domain, recovery, ARE/ACI, admission, authority, and effect decisions enter only as accepted owner-issued references;
5. deterministic compilation yields an `ExplicitComposition` plus receipt, or typed defects with no state mutation; and
6. finite positive and negative witnesses distinguish the candidate from a universal policy engine.
