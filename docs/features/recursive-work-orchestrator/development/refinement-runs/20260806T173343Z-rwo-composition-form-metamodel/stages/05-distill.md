# Stage 05 — Distill The Smallest Coherent Form Unit

Capability: `distill`  
Mode: `standard`  
Verdict: PASS at candidate-definition boundary; executable evidence absent

## Broad layer

The broad layer includes authored composite syntax, explicit graphs, runtime Work identities, journal history, recovery, domain decisions, reasoning/admission, authority, effects, ontology projections, validation, and promotion.

## Candidate reduction

| Candidate | Decision | Elimination condition |
|---|---|---|
| universal expression/evaluator | kill | inevitably absorbs external semantics and owners |
| seven unrelated top-level schemas | reject | duplicates source identity, provenance, compilation, defects, and validation |
| common envelope with generic operands/conditions | kill | universal attachment/evaluator seams remain |
| existing subtype + closed payload + existing owners + disjoint compile result | retain | smallest model that preserves both common compilation and local meaning |

## Smallest coherent unit

`CompositionFormSourceContract@candidate-2` contains exactly:

1. one immutable authored node typed as one existing form subtype and enclosed by `CompositeWorkDefinition`;
2. one exact closed subtype payload with form-specific operand fields;
3. references to existing `EventSelector`, `InputMapping`, `ReleasePolicy`, `SidecarLifecyclePolicy`, graph, and authority surfaces;
4. typed slots for exact external owner references, with no generic acceptance semantics;
5. immutable `CompilerProfile` plus disjoint `CompilationSuccess`/`CompilationRejection` targeting `WorkGraph`;
6. compiler-owned structural defects and a planned fixture contract.

No `FormInstance`, generic operand target, condition node, evaluator relation, late-arrival policy, unified defect set, or generic external reference belongs to the unit.

## Closure test

- Responsibility: define and deterministically compile structural composition syntax without interpreting domain or external-owner meaning.
- Inputs: exact authored form bytes, dependencies, existing owner references, and compiler profile.
- Outputs: one `WorkGraph` success or one structural rejection.
- Further split: source model without compilation cannot prove a common form architecture; compilation without closed payloads cannot preserve form meaning; compilation results without byte-domain lineage cannot prove determinism.
- Hidden glue: runtime matching, journal acceptance, debit, recovery, admission, authority, effects, and promotion are explicitly outside.

## Recomposition proof

```text
existing form subtype + closed payload
  -> existing selectors/mappings/policies/typed requirements
  -> compiler profile
  -> CompilationSuccess -> WorkGraph
  -> runtime only after separate admission and owner gates

invalid source
  -> CompilationRejection -> structural defects
  -> no WorkGraph or runtime/journal mutation
```

## Premortem

The most likely failure is reintroducing a “flexible” generic condition, plugin, reference, or policy slot. That convenience would silently recreate the killed universal evaluator. Repair: new semantics require a new exact subtype/schema version, owner route, compiler rule, and discriminating fixtures.
